# resume2026

# 첫 번째 반응형 포트폴리오 웹사이트

- **부트캠프 시작 후 한 달 동안 배운 내용으로 만든 첫 홈페이지입니다.**
- 화면 크기에 맞춰 레이아웃이 바뀌는 반응형 구현과 CSS 애니메이션 효과에 집중했습니다.

---

## ✨ 주요 특징

- **화면 크기에 맞춘 반응형 레이아웃**
  - 컴퓨터, 태블릿, 모바일 화면 크기에 따라 보기 편하게 바뀝니다. \*화면 너비가 줄어들어도 내부 콘텐츠나 글자가 깨지지 않도록 유연하게 설계했습니다.
- **자연스러운 CSS 애니메이션 효과**
  - **화면 fade in**: 메뉴를 눌러 새로운 페이지로 넘어갈 때 화면이 부드럽게 나옵니다.
  - **skills stick bar**: 페이지가 로드될 때 게이지가 올라갑니다.
  - **자기소개 카드**: 카드에 마우스를 올리면 크기가 커지고 숨겨진 설명글이 나타납니다.

---

## 📁 페이지 구성

- **1페이지 (이력서)**: 내 프로필 정보와 스킬역량이 있습니다.
- **2페이지 (자기소개)**:내 강점을 카드로 만들어 호버시 본문이 노출되게 만들었습니다.
- **3페이지 (프로젝트)**: 만든 작업물과 이미지를 배치 했습니다.
- **4페이지 (취미)**: 동영상과 사진을 활용해 취미를 소개했습니다.
